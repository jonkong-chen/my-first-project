# Pull Request Practice

## Purpose

Learn how to collaborate using GitHub Pull Requests.

## Learning Goals

- Create a feature branch
- Make changes in the feature branch
- Create a Pull Request
- Review and merge changes

# 拉取请求实践

## 目的

学习如何使用 GitHub 的拉取请求进行协作。

## 学习目标

- 创建功能分支  
- 在功能分支中进行修改  
- 创建拉取请求  
- 审查并合并更改
